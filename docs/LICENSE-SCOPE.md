# License scope

The `LICENSE` file is the MIT license supplied with the original ProgramSetting package.
That package now occupies the repository root and `src/jockeybench/`, excluding the
imported `src/jockeybench/research/` extension.

The published ActiveResearch source drop did not contain a separate license declaration.
Moving it into the unified package does not create or broaden a license grant. Its original
source records remain under `provenance/active-research/`. Ask the repository owners to
clarify the grant for that extension before relying on a repository-wide MIT license.

This is why the unified distribution does not declare a single MIT license expression for
all its contents. The existing MIT license remains unchanged and is distributed alongside
this scope note and `NOTICE.md`.

JRDB data, documentation, derived databases and experiment artifacts are not distributed
and are not covered by the code license.
